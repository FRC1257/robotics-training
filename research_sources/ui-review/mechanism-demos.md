# Mechanism and code demos: authorship and verification

Claude Code (reported model `claude-opus-5-5`) directly authored the shared mechanism UI stylesheet and JavaScript, including seven purpose-drawn SVG mechanism renderers, the plotting and readout design, controls and source annotations. Its session stopped before the page mounts were complete. The user explicitly approved Codex finishing integration using that design. Codex mounted the components in seven HTML pages, connected the builder/embed registry, and reconciled the UI with the final model contract. The original Claude components remain the basis of the interface.

The original, deterministic models are separate from the UI and from quoted team Java. They cover chassis aiming, speed readiness, bounded turret travel and equivalent targets, sensor-priority handling, elevator/wrist clearance, shoulder-before-extension, differential versus holonomic motion, and home/cage gates. Sensor flags and simple kinematics are teaching assumptions rather than measured robot physics. Java source annotations show a conceptual correspondence; no team Java is executed in the browser.

The seven MIT-licensed excerpts are pinned to full revisions in Team 254’s 2024 and Team 2910’s 2025 repositories. Full notices are included. `npm run verify:mechanism-sources` independently fetched all seven raw files and verified full-file hashes, exact excerpt lines and notices. The reproducible receipts and model assumptions are retained in the source inventories.

[Initial integrated CI](https://github.com/FRC1257/robotics-training/actions/runs/42962790538) passed 60 Node tests, 16 Java starter tests and 112 desktop/mobile browser tests. A separate read-only curriculum review found and corrected a low-pose example, partial-history time placement, unreachable-turret wording and paused-input ambiguity. The [subsequent run](https://github.com/FRC1257/robotics-training/actions/runs/42964432116) passed 114 browser checks, including the new sampled-step test and synchronized code-view poses. Actual browser screenshots were inspected for mechanism readability and source/animation correspondence. A later narrow-layout correction keeps changing annotation classes from reintroducing clipped SVG text; the final release CI verifies that correction.

Local browser use was disabled, so browser checks and screenshots were produced in GitHub Actions Chromium rather than a local browser. No hardware test, CAD reconstruction or execution of the full team codebases is claimed.

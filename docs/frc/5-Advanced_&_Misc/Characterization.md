# Characterization

The historical `frc-characterization` Python suite and its generated robot project are a different toolchain from the 2026 course. For current work, follow [SysId](Sysid.md), which includes an exercise, interpretation and safety precautions. Characterization estimates model coefficients from measured data; it does not certify a mechanism or make a poor fit reliable. Inspect the full traces and residuals, not only a single fit statistic.

# Robotics foundations

A robot is a system: mechanical choices, wiring, control software, people, and match decisions affect one another. These short lessons give every subteam a common vocabulary. Start with the system map, then use the other lessons as needed.

1. [Follow a signal through the robot](system.md)
2. [Electrical power, CAN, and troubleshooting](electrical.md)
3. [Mechanical ratios, interfaces, and maintenance](mechanical.md)
4. [Strategy and scouting with uncertainty](strategy.md)
5. [Safety and inspection](safety.md)

Work through each example with another student. Diagrams are conceptual learning aids, not construction drawings. For an actual robot, use current FIRST rules, component manuals and team-reviewed designs. Continue to [Team 1257 case studies](../robots/README.md) to trace these ideas in real source code and data.
